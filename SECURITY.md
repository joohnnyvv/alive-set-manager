# Security

This is prerelease software. Keep LAN access disabled unless needed, use a trusted network, and never forward the app’s HTTP/WebSocket port to the internet. Desktop filesystem operations are unavailable to remote browser clients.

Report suspected vulnerabilities privately through GitHub’s private vulnerability reporting if available, or contact the maintainer through their GitHub profile to arrange a private report. Do not publish tokens, personal diagnostics or exploit details in an ordinary issue.

CI audits dependencies and blocks reported moderate-or-higher vulnerabilities. Updates are manual for alpha; no unsigned executable is downloaded and launched automatically. A signed beta requires separate credentials, update verification and acceptance testing.
